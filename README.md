# Predictive-Analytics-Project

This repository contains a **Predictive Analytics and Sales Forecasting Model** created natively inside Microsoft Excel. It utilizes time-series data estimation formulas to project corporate growth patterns.

## Key Features
* **Trend Forecasting:** Implemented statistical linear trend algorithms (`TREND` and `FORECAST` logic vectors) to chart monthly future outcomes.
* **Historical Baseline Data:** Standardized dynamic datasets covering previous calendar periods to minimize anomaly weights.
* **Operational KPI Indicators:** Features high-level summary cards that compute metrics like Maximum Run Rate targets and forecasted next-quarter values.

## Technology Applied
* Microsoft Excel (Statistical Modeling, Trend Projections, Strategic Financial Layouts)
